## Work and responsibilities

Deploy an AI agent that helps customer teams investigate and resolve IT incidents. Connect it to production tools and establish which actions require supervision. Customer work also contributes reusable connectors, tools, and capabilities to the core product.

- Integrate the agent with monitoring, infrastructure configuration, and deployment pipelines.
- Use pilot evaluations to identify permissions, telemetry, and connector gaps.
- Ship fixes through product reviews and evaluation checks.
- Set technical roadmaps and guide customers through increasingly automated operations.

## Skills and eligibility

- 8+ years building production software across teams.
- Production LLM/agent work, tool connections, evaluation pipelines, and guardrails.
- Infrastructure as code, GitOps, CI/CD, and gradual deployment techniques.
- Technical customer discovery, architecture communication, and independent delivery.

## Preferences and supporting experience

- Incident management, on-call work, service-level objectives, and postmortems.
- Policy-based permissions and safety controls for automated actions.
- PagerDuty or similar operations platforms, consulting, founder experience, or agent ecosystem contributions.
