Help AI teams run demanding workloads efficiently on Modal infrastructure. Projects can involve model serving, training, audio processing, or scientific computing. Combine practical optimization with customer architecture discussions, demonstrations, and product feedback.

- Run experiments and proofs of concept to test proposed improvements.
