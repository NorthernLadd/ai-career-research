## Work and responsibilities

Join Google Cloud Consulting to build agent applications inside customer environments. Work on the connection between AI services, existing APIs, data sources, and security boundaries. The role includes deployment, evaluation, and turning repeated customer needs into reusable software.

- Move prototypes into production agent workflows, including tool connections and multi-agent systems.
- Integrate cloud AI products with customer APIs, data, and infrastructure.
- Build evaluations and monitoring for accuracy, safety, and response time.
- Co-develop with customer engineers and return recurring product gaps to Google teams.

## Skills and eligibility

- Bachelor’s or master’s studies in engineering, CS, or a related field.
- Python or comparable software development experience.
- Experience launching production AI solutions and designing AI systems on cloud platforms.
- Experience with structured/unstructured data pipelines, vector databases, and retrieval-augmented generation.
- English proficiency and US presence for the program.

## Preferences and supporting experience

- Return to study after the internship and availability for a full 12 weeks.
- Multi-agent development using tools such as LangGraph, CrewAI, or ADK.
- Technical discovery, agent state management, detailed tracing, and metrics such as tokens per second or cost per request.
