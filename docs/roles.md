# Career profiles

Each profile pairs a job title you can search for with a small project that samples the work. The projects and routes below are suggestions. Employer requirements vary by team and seniority.

## Data scientist

A data scientist turns a decision into a measurable question. For example, a transit team might predict late arrivals so dispatchers can intervene. The scientist defines “late,” checks for missing observations, trains a model, and compares its errors across routes. BLS identifies a bachelor's degree as the typical entry-level education. [BLS occupational profile](https://www.bls.gov/ooh/math/data-scientists.htm)

**Route in.** Start with SQL, statistics, and Python through coursework or an analyst role. Try forecasting delays from public transit records. Reserve the most recent month for testing and report where a simple historical average beats your model.

## Model evaluations engineer

Anthropic uses the title **Research Engineer, Post-Training Model Evaluations**. This specialty asks whether changes to a trained model improve the behavior users care about. A test designer needs representative tasks, clear scoring rules, and a way to investigate surprising results. [Anthropic job titles](https://www.anthropic.com/careers/jobs)

**Route in.** Software testing and experimental design are useful starting points. Write 30 questions about a public handbook, mark the passages that support each answer, and compare two model configurations. Report unsupported answers separately from incomplete ones.

## Inference performance engineer

Inference is the step where a trained model produces a response. A **Performance Engineer, Inference Systems** investigates how hardware and software affect response time, throughput, and cost. A change that processes more requests per second can still make one user wait longer. [Anthropic job titles](https://www.anthropic.com/careers/jobs)

**Route in.** Build from backend engineering, operating systems, or performance testing. Run a small model locally. Compare individual requests with batches and plot both requests per second and the wait time for the slowest 5% of requests.

## Interpretability researcher

A **Research Scientist, Interpretability** studies how a model arrives at a result. A **Research Engineer, Interpretability** may build tools to inspect activations or run interventions across many inputs. Both routes reward careful experiments that distinguish a correlation from a causal explanation. [Anthropic interpretability engineering](https://www.anthropic.com/research/engineering-challenges-interpretability) · [Employer titles](https://www.anthropic.com/careers/jobs)

**Route in.** Start with linear algebra, neural networks, and reproducing published experiments. Train a small image classifier, cover one part of each input, and record when its prediction changes. Explain which other factors could account for the result.

## Pre-training data infrastructure engineer

A **Pre-training Data Infrastructure Engineer** builds systems that prepare data for training. A team needs to know where records came from, which duplicates were removed, and how to recreate the exact input for a previous run. [Anthropic job titles](https://www.anthropic.com/careers/jobs)

**Route in.** Database development and data engineering offer relevant experience. Build a pipeline for a public-domain text collection. Track source identifiers, detect repeated documents, and show that two runs on identical input yield identical output.
